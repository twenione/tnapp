## 0. 이 문서의 성격 (D-055)

**v1 이후의 결정을 반영한 현재 상태의 통합 정리다. 새 결정을 담지 않는다.**

```
충돌 시   결정 기록 > 로드맵 v2 · UI 지침 > 관리 지시서 · 로깅 스킬   (D-012, D-037)
개정      v2 는 결정이 생길 때마다 개정하지 않는다
          통합판은 Phase 경계에서만 발행한다 — 다음 발행은 G3 시점
```

각 항목 옆의 `(D-nnn)`은 근거 결정이다. **결정 번호를 인용할 때는 해당 결정서 원문을 확인한다**(D-036 이전 오기 사례).

## 2. 공통 사양

### 2.1 저장소 (D-006)

```
twenione/tnapp               퍼블릭 — 브랜치 보호 사용을 위해
twenione/tnapp-failure-log   프라이빗 — 빌드 로그 전문
```

**실패 기록 저장소 쓰기는 워크플로 경로로만 한다**(D-049). 로컬 실행 시 쓰기 스크립트가 거부하고, 커밋에 워크플로 신원과 Actions run 링크를 남긴다(D-052).

### 2.2 모듈

```
:core-guide   순수 JVM. Android 의존성 0
:app          서비스 · UI · TTS · 카메라 · 로거
:replay       JVM CLI
:synth        JVM CLI
```

### 2.3 절대 규칙

```
엔진에서 시계 · 난수 · I/O 직접 접근 금지. 시각은 frame.timestamp 에서만
파라미터를 코드 상수로 두지 않는다. 전부 GuideConfig
실측 GPX · 세션 로그를 저장소에 넣지 않는다 (비식별 최소 구간 픽스처만 예외 — D-040)
force push 금지
프로덕션 코드에 테스트 편의를 위한 분기를 두지 않는다         (D-043)
```

### 2.4 검사 장치 공통 요건 (D-053)

```
모든 검사는 실제로 FAIL 하는 반증 입력을 함께 커밋한다
검사 대상 목록은 사람이 아니라 도구가 열거한다
검사는 판정의 근거 데이터를 직접 본다 (부산물이 아니라)
```

**반증 입력이 없는 검사는 병합하지 않는다.** 지시서에서 매번 명시할 필요가 없다.

### 2.5 좌표와 고도

로컬 ENU 평면 투영, 2D 미터 단위.

```
판정 (매칭 · 이탈 · 종착)   고도 미사용
안내 콘텐츠                GPX <ele> 만 사용                   (D-054)
기기 측정 고도              GPS 고도 · 기압계 모두 사용 금지      (D-054)
```

### 2.6 로그 시간 규약 (D-040, D-045)

```
t      사건 발생 시각. 스트림별 단조
       envelope 는 (stream, event_stream) 단위로 검사
seq    기록 순서. 전체에서 엄격 증가
replay 는 loc 수 ≠ guide 수 이면 즉시 실패. guide.src_seq 로 원본 참조
code_hash  git commit SHA (로컬 빌드는 -dirty)
```

```

보류   imu, baro, ar, stt   — 실험 스트림. 미동결
```
